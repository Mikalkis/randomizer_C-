# Rand — генератор случайных чисел

Маленькая настольная программа на C++ (WinAPI): случайное число в диапазоне
Min–Max с режимом «Без повторов» и историей из 5 последних значений.

Это порт исходной версии на Python (tkinter, `random_generator.py`): интерфейс,
сообщения об ошибках и все режимы сохранены.

## Возможности

- Случайное число в диапазоне **Min…Max** (включительно).
- Режим **«Без повторов»**: число не повторяется, пока не выпадут все значения
  диапазона; когда числа закончатся — кнопка «Пуск» блокируется с сообщением
  «Все числа использованы».
- **История**: последние 5 выпавших чисел, последнее подсвечивается.
- **«Очистить»** сбрасывает использованные числа и историю.
- Окно фиксированного размера (210×200), центрируется на экране.
- Ввод проверяется: нецелые значения («Введите целые числа») и диапазон
  с Min > Max («Минимум больше максимума») показывают сообщение об ошибке.

## Сборка

Нужен компилятор C++ и CMake (3.16+). Проект использует только WinAPI —
внешних зависимостей нет.

```sh
cmake -S . -B build
cmake --build build --config Release
```

Готовый файл: `build/rand.exe` (MinGW) или `build\Release\rand.exe` (MSVC).

Можно собрать и без CMake:

```sh
# MinGW (g++)
g++ -O2 -Wall -Wextra main.cpp -o rand.exe -lgdi32
```

```bat
rem MSVC (клон консоли Developer Command Prompt)
cl /W4 /EHsc /utf-8 main.cpp user32.lib gdi32.lib /Fe:rand.exe /link /subsystem:windows
```
